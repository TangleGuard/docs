👋 Glad you're here!

TangleGuard is a _static code analysis_ tool that helps to maintain a modular codebase.

The user can browse the codebase as directed graph diagram and enforce package and module dependency rules. That way e.g. layered architectures, hexagonal architectures or clean architectures can be setup.

Such architectures are easy-to-maintain, flexible, scalable and cost effective.

I can be used for Modular Monoliths or a single Microservices.

## Components

TangleGuard consists of two tools:

- 📺 **GUI** a desktop app to monitor and setup the architecture
- 🔎 **CLI** tool that runs in CI-Pipeline to enforce architectural rules

Both are available for all major operating systems.
Having those tools allow to keep the intended structure in place.

The Code analysis is done in [Rust](https://www.rust-lang.org/).
Therefore it's highly performant and reliable.

## Who It's For

TangleGuard is built for developers, teams and architects which work on **modular codebases** and which want to keep their maintenance effort/costs low in the long run.

The underlying codebase could be of a broad range of types:

- Modular Monoliths (Moduliths)
- Specific Microservices
- CLI tools
