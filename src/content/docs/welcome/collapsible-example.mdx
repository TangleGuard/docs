# Using Collapsible Components

The `Collapsible` component allows you to create expandable sections in your documentation. This is perfect for FAQ sections, detailed explanations, or any content you want to keep accessible but not always visible.

## Basic Usage

<Collapsible title="Basic Example">
This is a simple collapsible section. You can put any markdown content here, including:

- Lists
- **Bold text**
- `code snippets`
- Links and more!
</Collapsible>

## Variants

The component supports different variants to match different types of content:

<Collapsible title="Information Section" variant="info">
This is an informational collapsible section. Use this for additional context or helpful information that users might want to reference.

```javascript
console.log('This is some example code!');
```
</Collapsible>

<Collapsible title="Helpful Tips" variant="tip">
This is a tip section. Great for best practices, recommendations, or helpful hints.

> **Pro tip:** You can nest other components inside collapsible sections too!
</Collapsible>

<Collapsible title="Important Warning" variant="caution">
This is a caution section. Use this for important warnings or things users should be careful about.

<Badge text="Important" variant="caution" />
</Collapsible>

<Collapsible title="Critical Information" variant="danger">
This is a danger section. Use sparingly for critical warnings or breaking changes.
</Collapsible>

## Open by Default

<Collapsible title="This Section is Open by Default" open={true}>
Sometimes you want a section to be expanded by default. Just add the `open` prop!

This is useful for important information that users should see immediately but might want to collapse later.

## Code Example

<Collapsible title="How to use in your MDX files">
To use the Collapsible component in your MDX files, first import it:

```mdx
---
title: Your Page Title
---
import Collapsible from '../../../components/Collapsible.astro';

# Your Content

<Collapsible title="Your Section Title">
Your collapsible content goes here!
</Collapsible>
```

Available props:
- `title` (required): The title shown in the header
- `open` (optional): Whether the section is open by default (default: false)
- `variant` (optional): Visual style - 'default', 'info', 'tip', 'caution', or 'danger'
</Collapsible>
