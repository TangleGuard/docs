---
title: Javascript
---

Javascript support is in early stage. The resolved imports includes the basic `import` statements.

Re-Exports are being ignored at the moment.
Dynamic imports are also not taken into account yet.

## Abstraction Level Mapping

Same like in Rust, packages are the top level abstraction, followed by the modules.

| Level | Component |
| ----- | --------- |
| L1    | Packages  |
| L2    | Modules   |
