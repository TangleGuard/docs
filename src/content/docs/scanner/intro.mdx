title: Background
---

A major part of TangleGuard are the scanners. They are written in Rust and hence very fast and reliable. They traverse the file system and basically extracts all dependencies within the code for one specific language.

This results in an abstraction of the architecture, stored in one object, which Tangleguard uses to create visualization from it the code.

Currently those two languages

- Rust
- JavaScript/TypeScript

Go is planned.
