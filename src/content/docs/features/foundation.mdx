## Workspace Abstraction

TangleGuard's features are enabled by a **workspace abstraction**.

It's an object which stores the components their relationships/dependencies from workspaces like [NPM workspaces](https://docs.npmjs.com/cli/v11/using-npm/workspaces) or [Cargo workspaces](https://doc.rust-lang.org/cargo/reference/workspaces.html).

This abstraction is the result of the scanners - see [scanner](/scanner/intro).

This simplified representation of a whole codebase leverages the visualization, the validation and the metics.
