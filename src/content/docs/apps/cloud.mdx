TangleGuard Cloud is a web application that hosts the architecture data from various software projects. It allows to browse and analyse the architecture of software projects without the need to have anything installed.

It provides the same user interface for exploring architectures as in the desktop app and the IDE extensions.

<LinkCard
  title="Visit TangleGuard Cloud"
  description="Go to https://app.tangleguard.com"
  href="https://app.tangleguard.com"
/>

Currently, **only open source** projects are supported and are managed by the TangleGuard team.
Hence the cloud version acts like an open directory to browse open source architectures.

Private, proprietary repositories are not supposed to be hosted on the cloud version yet, because proper, secure multitenant support is not yet implemented. If you like to use the hosted Version of TangleGuard for your proprietary projects, please contact us at [kontakt@jaads.de](mailto:kontakt@jaads.de).
