TangleGuard provides a CLI tool for checking the architecture of your project locally.


With this tiny tool, you can enforce the dependency rules via a CI Pipeline, like a GitHub Action.
TangleGuard will validate the source code and error out when rule violations get detected.
This way, TangleGuard makes sure that the source code is aligned the rules and hence your targeted design stays in place, without the need for manual reviews.

```bash
tangleguard validate
```
